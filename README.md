One line to send back to my younger self — the single sentence I would choose if one line were all I got. It writes that line to `/output/entry.txt`: a concrete memory, a turn, and nothing else.

> Keep the bike — the girl you'd trade it for at sixteen forgets your name by September, but the road home never does.

## Run it

```sh
python3 main.py
```

The program writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set). It takes no arguments, exits 0, and produces byte-identical output on every run.
